3. 수집·전송·공유

앱은 위 가족 정보와 기록을 운영자의 서버로 전송하지 않으며, 해당 정보를 운영자에게 제공하는 가입·실시간 가족 공유 기능은 없습니다. 광고·사용 분석·오류 보고용 외부 수집 SDK와 결제 기능은 이 버전에 포함하지 않았습니다. WebView와 계산 모듈 사이의 통신은 휴대폰 내부의 루프백 주소에서 처리합니다.

메시지를 복사하여 카카오톡·문자 등 다른 앱에 붙여넣고 전송하는 것은 사용자가 직접 선택합니다. 다른 앱으로 전달한 내용에는 해당 서비스의 개인정보처리방침이 적용됩니다. 가족에게 자동으로 메시지를 보내지 않습니다.

4. 보관 기간과 삭제

앱의 가족 정보와 기록은 앱 전용 내부 저장 공간에 보관됩니다. 사용자는 가족 관리에서 정보를 수정하고 앱의 전체 기록 초기화로 내부 기록을 삭제할 수 있습니다. 앱 삭제 또는 Android의 앱 저장 공간 초기화 시 내부 기록이 삭제됩니다. 운영자가 보유한 가족 기록은 없으므로 원격 열람·수정·복원은 제공하지 않습니다.

별도로 저장한 백업 파일과 다른 앱에 전달한 메시지는 앱 초기화로 삭제되지 않습니다. 해당 저장 위치나 서비스에서 직접 삭제해 주세요. 문의 이메일을 보내면 이메일 주소와 문의 내용이 문의 처리 과정에서 사용됩니다. 문의 시 가족의 생년월일, 백업 비밀번호 등 불필요한 개인정보는 보내지 마세요.

5. 암호화 백업과 복원

백업은 사용자가 지정한 비밀번호로 암호화한 파일을 시스템 파일 선택기에서 고른 위치에 저장합니다. 복원은 사용자가 선택한 파일과 비밀번호로 진행합니다. 운영자는 비밀번호를 저장하거나 복구하지 않습니다. 비밀번호를 잊으면 백업을 복원할 수 없습니다.

Google Drive 등 클라우드 저장 위치를 직접 선택할 경우 파일이 해당 서비스에 저장될 수 있으며, 그 서비스의 정책이 적용됩니다. 앱 삭제 전 기록이 필요하다면 백업하고, 파일과 비밀번호를 서로 다른 안전한 위치에 보관하세요.

6. 권한과 보호 조치

알림은 사용자가 허용한 경우 휴대폰에서 예약·표시합니다. 알림 문구에는 가족 이름이나 상세 코칭 내용을 넣지 않습니다. 기기 재시작 후 알림을 다시 예약하기 위해 재시작 알림을 수신합니다. 절전 설정에 따라 알림이 지연될 수 있습니다.

백업·복원의 파일 접근은 시스템 선택기에서 사용자가 선택한 위치·파일을 이용합니다. 선택형 앱 잠금은 Android에 설정된 기기 인증을 사용하며 앱이 기기 잠금 비밀번호나 생체정보를 직접 받거나 저장하지 않습니다. 앱은 별도의 가족 서버에 연결하기 위해 인터넷 권한을 사용하지 않습니다.

7. 아동과 가족 정보

첫 출시 앱은 성인 부모가 관리하는 용도이며 자녀의 별도 계정 가입을 요구하지 않습니다. 자녀의 정보는 보호자가 필요한 범위에서 등록·관리·삭제할 수 있습니다. 기록은 해당 휴대폰 사용자가 볼 수 있으므로 기기 접근과 백업 관리에 유의해 주세요.

8. 가상 가족과 해석 안내

가상 가족 체험은 실제 가족 기록과 분리된 예시 데이터입니다. 사주명리학과 MBTI 설명은 생활 참고용이며 실제 성격이나 건강·사고를 확정적으로 판정하는 정보가 아닙니다. 반려동물 생활 성향 코드는 보호자의 관찰에 따른 재미용 분류입니다.
